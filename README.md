# Baseball Stats

A single-page MLB player stats lookup built on the public [MLB Stats API](https://statsapi.mlb.com).

Open `index.html` in a browser (no build step). Search a player, pick them from the dropdown, and view their bio, current-season and career summary, and a sortable year-by-year table. Two-way players get Hitting and Pitching tabs. Player pages are linkable via `#player=<id>`.
